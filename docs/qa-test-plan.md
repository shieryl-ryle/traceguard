# QA Test Plan — TraceGuard

## 1. Gates
| Gate | Command | Must pass before |
|---|---|---|
| Typecheck | `python -m mypy traceguard app.py` | every PR |
| Unit | `python -m pytest -m "not live"` | every PR |
| Live AI (spends Vertex quota — run only when asked) | `python -m pytest -m live` | merge of any `traceguard/ai/` change |
| E2E (deployed) | `curl -fsS "$SERVICE_URL/_stcore/health"` + manual UJ-001 in a clean browser (TC-010) | every redeploy; final check before submission |

`$SERVICE_URL` is the Cloud Run URL. Unit tests mock the Gemini client; live tests need ADC and
the env vars in System Design §4.

## 2. Test cases

## 3. Exit criteria
- All gates green.
- Every P0 feature in the PRD has at least one passing TC.
- Every BR-### has a TC or a reviewer check.
- Expected vs actual table per case (for the deck) filled from TC-004 output. No claims of
  production accuracy or time saved.
